# Экспериментальная сборка FPS

Дата: 6 октября 2026. Компиляция и линковка Win32 Release прошли успешно.
Первая установленная сборка вылетела при запуске пользователя. Причина
установлена по свежему дампу; исправленная сборка установлена. Пользователь
подтвердил 40 минут стабильной игры. Количественный прирост FPS ещё не измерен.

## Основа

Оригинальная ветка `generals-mods` сохранена. Контрольная сборка использует
общественный проект [GeneralsGameCode](https://github.com/TheSuperHackers/GeneralsGameCode)
на фиксированном коммите `b805c12ee1aedc0a4b241006803b8e04bbf288a6`.
Он основан на исходниках EA, поддерживает современный MSVC и уже содержит
разделение отрисовки и игровой логики, а также интерполяцию ряда объектов.
Это работа авторов общественного проекта. Она не представляется нашим новым
рендерером: исполняемый файл остаётся Win32 / DirectX 8.

Наши добавления: включаемый переменной окружения режим FPS, фиксированная
целевая частота симуляции 30 Гц в этом режиме, CSV-профилирование и скрипты
воспроизводимой сборки/установки. Это отдельная сборка на общественной основе,
а не успешная сборка всех изменённых исходников из оригинального дерева EA.
Изменения WinMain/W3DDisplay в оригинальном дереве не перенесены автоматически.

## Исправление вылета при первом запуске

Дамп `CrashMZ-20261006-202624-0a05454-pid12964.dmp` показал исключение
`0xc0000005` внутри установленного GenTool `d3d8.dll`, смещение `0x186456`:
чтение адреса `0x400000`. Новый CSV содержал только заголовок. Старый
ReleaseCrashInfo.txt от января 2026 не относится к этому вылету.

В экспериментальной сборке DX8Wrapper теперь загружает системный d3d8.dll
по абсолютному пути, используя `GetSystemDirectoryW` и `LoadLibraryExW` с
`LOAD_LIBRARY_SEARCH_SYSTEM32`. GenTool в папке оригинальной игры сохранён.
Правила загрузки описаны в
[документации Microsoft](https://learn.microsoft.com/en-us/windows/win32/api/libloaderapi/nf-libloaderapi-loadlibraryexw).
Воспроизводимое исправление: `Apply-SystemD3D8Patch.ps1`, применяемое сборочным
скриптом при `-ExperimentalFps`.

Проверки: `Test-SystemDirect3D8.ps1` успешно загрузил системный Direct3D8 из
рабочей папки установленной игры с локальным GenTool и проверил наличие
экспорта Direct3DCreate8. В новом exe отсутствует статический импорт d3d8.dll,
который мог бы загрузить локальный прокси до выполнения нашего кода.
Полная пересборка и линковка успешны. Новый exe установлен с резервной копией
предыдущего тестового файла. Пользователь подтвердил 40 минут стабильной игры.
Контрольная копия этой версии находится в `.build/stable-fps-20261006`;
SHA256 exe: `8CB02026BDF4478681F077CA221C60A0E18CAB21D4A99D1BC1E0CD83347885CF`.

В скачанной копии CMake получает зависимости по архивам тех же фиксированных
коммитов, поскольку встроенный Git не смог создать origin/HEAD. Для ресурсов
иконки и DPI используется `winres.h` Windows SDK вместо MFC `afxres.h`.
Для встроенного браузера установлен Microsoft ATL.

## Сборка и установка

```powershell
.\tools\Build-CommunityBaseline.ps1 -ExperimentalFps
.\tools\Install-ExperimentalFpsBuild.ps1 -WhatIf
.\tools\Install-ExperimentalFpsBuild.ps1
```

Сборка находится в `.build\community-baseline-ninja\GeneralsMD\generalszh.exe`.
По умолчанию установка добавляет в `E:\C&C ZH GPTMOD\CaCGZH`:

- `generalszh-fps-test.exe` — экспериментальный исполняемый файл;
- `Test-FPS-30.cmd` — контрольный режим с лимитом 30 FPS;
- `Test-FPS-Uncapped.cmd` — отрисовка без программного лимита FPS.

Оригинальные `generals.exe`, `game.dat` и GameData.ini не изменяются.
Повторная установка сохраняет существующие тестовые файлы в отдельных `.bak`.
Хеш установленного файла записан в `.build\experimental-install.json`.

## Проверка

1. Закрыть игру и запустить `Test-FPS-30.cmd`. Проверить меню, разрешение
   3440×1440 и небольшую схватку. Записать FPS и время строительства одного
   и того же здания.
2. Закрыть игру. Сохранить копию `FramePerformance.csv` из пользовательской
   папки данных Zero Hour: следующий запуск перезапишет файл.
3. Запустить `Test-FPS-Uncapped.cmd`, повторить тот же сценарий. Проверить
   фактический FPS, скорость строительства, движения и таймеров.
4. Проверить большую армию, частицы, воду, тени, прокрутку камеры, паузу,
   сохранение/загрузку и воспроизведение повтора.

Сначала тестируется локальная схватка. Современный MSVC не обеспечивает CRC
совместимость этой основы с исходным retail-клиентом для сетевой игры.
Рост FPS и корректность скорости игры пока не подтверждены измерениями.
Если запуск завершится ошибкой, нужен её текст или свежий ReleaseCrashInfo.txt.

Переменная `GENERALS_RENDER_FPS` принимает `0` (без лимита) либо целое число
от 30 до 1000. Без неё исполняемый файл использует поведение общественной
основы. `GENERALS_FPS_PROFILE=1` включает CSV-профиль; без неё записи нет.
`update_ms` включает обновление и отрисовку, `limiter_ms` — остаток цикла,
включая ожидание. Отдельного измерения GPU этот профиль не делает.
