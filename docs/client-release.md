# Установочный клиент Generals GPT Mod

Текущий пакет содержит обе установленные игры: CaCG (Generals) и CaCGZH
(Zero Hour / MOD SymBioz). Сборки x64 независимы: для Generals используется
проверенный DXGI-вывод и актуальное меню DLSS/DLAA, для Zero Hour — её
отдельная проверенная сборка. Игровые данные входят только в локальный пакет,
а не в Git. Личные настройки, сохранения, серийные номера и тестовые сборки
не включаются в архив.

Запуск выполняет `generals.exe` в каждой игровой папке. Существующие ярлыки
рабочего стола продолжают указывать на этот файл. Launcher выбирает свой
`Client/generals-client.exe`, включает D3D12 backend и запускает игру с
правильной рабочей папкой. Generals получает разрешение основного монитора
и окно без рамки; Zero Hour сохраняет свой проверенный режим запуска.
Режим сглаживания берётся из настроек игрока. Принудительный DLAA используется
только диагностическим скриптом проверки ярлыков.

В `Client` находятся графический мост, подписанные NVIDIA Streamline DLL,
Visual C++ runtime и лицензии. BAT-файлы для обычного запуска не нужны.
Предыдущие тестовые сборки убираются из игровых папок после успешной проверки
ярлыков, а их восстановимая копия остаётся в `.build/client-release`.

Сборка локального выпуска:

```powershell
.\tools\Prepare-ClientRelease.ps1
.\tools\Test-ClientShortcuts.ps1
.\tools\Build-ClientPackage.ps1
.\tools\Clean-ClientTestFiles.ps1
```

`dist/Generals-GPT-Setup.exe` — самостоятельный установщик с встроенным ZIP64.
Он предлагает папку установки, распаковывает CaCG/CaCGZH и создаёт либо
обновляет ярлыки. Для каждого файла проверяется SHA256. ZIP-срез использует
собственные относительные смещения, независимо от размера установщика.
Файлы сначала распаковываются во временный файл рядом с местом назначения;
целевой файл заменяется после успешной проверки суммы. Путь каждой записи
проверяется на принадлежность выбранной папке. Сохранения и Options.ini в
Документах пользователя установщик не изменяет.

`dist/Generals-GPT-Client.zip` — тот же чистый клиент для ручной распаковки.
Нужно распаковать обе папки рядом, затем запускать соответствующий generals.exe.
`dist/release.json` фиксирует размер и контрольные суммы обоих артефактов.

Выпуск от 7 октября 2026: 10 419 файлов, 5 591 937 537 байт после распаковки;
архив и самостоятельный установщик имеют размер около 3,8 ГБ каждый.
Проверены реальные ярлыки обеих игр, установка в отдельную папку, SHA256
каждого распакованного файла и запуск обеих игр из этой папки с DLAA, звуком
и штатным выходом. Старые тесты удалены из игровых папок; резервная копия
для восстановления хранится отдельно от клиента и не входит в выпуск.

Диагностика установщика без GUI:

```powershell
.\dist\Generals-GPT-Setup.exe --verify
.\dist\Generals-GPT-Setup.exe --extract E:\GeneralsGPT\.build\client-release\install-check
.\tools\Test-ClientShortcuts.ps1 -GameRoot E:\GeneralsGPT\.build\client-release\install-check -Direct
```

`--verify` проверяет все встроенные файлы без распаковки. `--extract` выполняет
тот же алгоритм распаковки и проверки без создания ярлыков, чтобы тестовая
установка не меняла рабочие ярлыки.
